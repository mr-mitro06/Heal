🌱 Heal - Daily Nature Tracker

Heal is an interactive, gamified mobile-first web application designed to encourage sustainable daily habits. By combining self-reflection with engaging mini-games, Heal makes it fun to track your environmental footprint and learn about the real-world impact of your choices.

✨ Features

🌍 Daily Eco-Missions: Complete a daily check-in quiz about your habits (bathing, commuting, eating, screen time, and sleep).

🧠 Science-Backed Feedback: Get immediate feedback and learn interesting science facts about how your choices impact the environment.

🎮 Eco-Arcade: Play 5 different interactive mini-games to earn tokens.

🛍️ Theme Shop: Use your hard-earned tokens to unlock beautiful, dynamic UI themes (Forest, Ocean, Sunset, Rose, Midnight).

📈 Progression System: Level up, earn XP, maintain daily streaks, and collect coins and game points.

💾 Local Storage: Your progress, unlocked themes, and stats are automatically saved to your browser.

🕹️ Mini-Games

The Arcade features 5 custom-built mini-games, each focusing on a different environmental concept:

💡 Energy Saver: A fast-paced reaction game where you must quickly tap to turn off the glowing yellow lights.

♻️ Trash Master: Sort descending items correctly into "Compost" or "Recycle" bins.

🚰 Pipe Patrol: A whack-a-mole style game where you must tap bursting water leaks to fix them and save water.

🌳 Tree Life: A clicker game where you dig a hole, plant a seed, and water it as fast as you can to grow a full tree.

☁️ Smog Smash: Tap on dark smog clouds to clear the sky, but be careful not to tap the birds!

🛠️ Tech Stack

This project is built as a highly portable, single-file web application using modern frontend technologies via CDNs:

React (v18): Core UI framework and state management.

Babel (Standalone): In-browser JSX compilation.

Tailwind CSS: Utility-first styling for responsive, beautiful layouts.

Canvas Confetti: For celebratory particle effects.

Lucide Icons: (Implemented via custom inline SVGs for maximum portability).

HTML5 / CSS3: Standard web APIs, CSS animations, and custom scrollbar handling.

🚀 Getting Started

Because Heal is built entirely within a single HTML file without the need for a build step, getting started is incredibly simple:

Clone this repository or download the source code.

Open the index.html file directly in any modern web browser (Chrome, Firefox, Safari, Edge).

Optional: To view it on your mobile device, you can serve the directory using a simple local server (e.g., python -m http.server or VS Code's Live Server extension) and access your local IP.

📱 Design Philosophy

Heal was designed with a "mobile-first" mindset. The UI features large, tap-friendly buttons, smooth CSS animations (pop-in, fade-in, floating effects), and a hidden scrollbar design to mimic the feel of a native mobile application while running directly in the browser.
